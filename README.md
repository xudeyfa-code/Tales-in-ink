# ديوان حذيفة محمد نور

موقع أدبي عربي RTL يعمل بـ HTML وCSS وJavaScript فقط، ولا يحتاج إلى Backend.

## التشغيل في VS Code

1. افتح مجلد المشروع في VS Code.
2. شغّل `index.html` عبر إضافة Live Server، أو افتحه مباشرة في المتصفح.
3. استخدم القائمة للانتقال بين الرئيسية والديوان والمفضلات وعن الشاعر.

> لأن الموقع يستخدم JavaScript Modules، يفضّل Live Server عند التشغيل المحلي.

## إضافة قصيدة

افتح `data.js` وأضف عنصرًا جديدًا إلى مصفوفة `poems` باستخدام الشكل التالي:

```js
 poem('new-poem', 13, 'عنوان القصيدة', 'الوصف', [
  'البيت الأول\\nالشطر الثاني',
  'البيت الثاني'
], 'مقدمة القصيدة')
```

التصنيف يجب أن يكون واحدًا من القائمة الرسمية الموجودة في `categories` داخل `data.js`.

ستظهر القصيدة تلقائيًا في الفهرس والبحث والصفحة الديناميكية، ويضاف التوقيع تلقائيًا. لا تضع التوقيع داخل `verses`.

## التخصيص

- الألوان والخلفية: بداية `styles.css` داخل متغيرات `:root`.
- الخطوط: قائمة Google Fonts في `index.html` وقائمة اختيار الخط في `app.js`.
- الصور: يمكن إضافة مجلد `assets` وربط الصور من `styles.css` أو داخل البطاقات.
- المفضلات وإعدادات الوضع: تحفظ محليًا في `localStorage`.

المحتوى الحالي مدخل من النص المقدم في المحادثة. أي نص غير مؤكد يجب مراجعته يدويًا قبل النشر.
